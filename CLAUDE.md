# Fábrica de prueba: Lista de precios del market

## Qué es
Página web simple (HTML, CSS y JavaScript, sin frameworks) que muestra la lista
de precios de un minimarket en El Alto, Bolivia. Se publica con GitHub Pages.

## Reglas para todos los agentes
1. Antes de cualquier tarea, lee brain/decisiones.md y brain/convenciones.md.
2. Nunca trabajes directo en la rama main. Cada tarea va en su propia rama.
3. Si tomas una decisión nueva de arquitectura o estilo, regístrala en brain/decisiones.md.
4. Si algo contradice el brain, detente y avisa.
5. Todo el texto visible de la página va en español.

## Mapa del brain
- brain/decisiones.md → decisiones tomadas, con fecha y motivo
- brain/convenciones.md → cómo se escribe el código
- brain/producto.md → qué debe hacer la página y para quién
